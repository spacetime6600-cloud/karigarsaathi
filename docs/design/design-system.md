# KarigarSaathi Phase 5 Design System & Token Taxonomy

## 1. Color Palette (Earth Tones & High-Contrast Archetype)

- **Background & Canvas**:
  - Warm Off-White: `#FFF9EF`
  - Pale Sand: `#F3E8D5`
  - Surface: `#F7F9FF`
  - Surface Container Lowest (Cards): `#FFFFFF`
  - Surface Container Low: `#EDF4FF`
  - Surface Container High: `#DFE9F7`

- **Primary Brand & Structure (Deep Indigo)**:
  - Base: `#001D36`
  - Container: `#17324D`
  - Fixed / Light: `#D1E4FF`
  - Fixed Dim: `#AFC9EA`

- **Primary Action (Terracotta)**:
  - Base: `#C65A35` (`#A13F1C`)
  - Hover: `#A64A2B` (`#812805`)
  - Container: `#FD835B`
  - Fixed: `#FFDBD0`

- **Highlight & Accents (Restrained Marigold)**:
  - Accent / Focus: `#FFB955` (`#FFDDB5`)
  - Container: `#462B00`

- **Feedback & Semantics**:
  - Success: `#2E7D32` (Container: `#E8F5E9`)
  - Error: `#BA1A1A` (Container: `#FFDAD6`)
  - Warning: `#E65100` (Container: `#FFF3E0`)

## 2. Typography

- **Primary Font Family**: `Noto Sans` (with native script support for Devanagari, Bengali, Odia, and Telugu).
- **Type Scale**:
  - `display-lg`: 32px / Line Height 40px / Bold (700)
  - `headline-lg`: 24px / Line Height 32px / Bold (700)
  - `headline-lg-mobile`: 20px / Line Height 28px / Bold (700)
  - `title-md`: 18px / Line Height 24px / Semi-bold (600)
  - `body-lg`: 18px / Line Height 28px / Regular (400)
  - `body-md`: 16px / Line Height 24px / Regular (400)
  - `label-lg`: 14px / Line Height 20px / Semi-bold (600)
  - `label-sm`: 12px / Line Height 16px / Medium (500)

## 3. Shapes, Radii & Spacing

- **Grid Base**: 8px soft grid.
- **Radii**:
  - Controls, Buttons, Inputs: 12px (`rounded-md`)
  - Major Panels, Cards, Modals: 16px (`rounded-lg`)
  - Pill badges & full circles: `rounded-full`
- **Touch Target Minimum**: 48px × 48px across all clickable elements.
- **Focus Rings**: High-contrast 2px solid Marigold (`#FFB955`) with 2px offset.
